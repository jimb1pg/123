## 三、關鍵技術決策與原因

> 這節最重要。口試被問到時，答案都在這裡。

### 資料層

| 決策 | 原因 |
|---|---|
| FinMind 用 `taiwan_stock_daily`，不用 `_adj` | `_adj`（還原股價）需付費贊助帳號，免費帳戶呼叫會失敗 |
| 抓不到自動切換另一個來源 | 單一來源限流或失效時不讓畫面開天窗 |
| 所有 API 呼叫加 `@st.cache_data(ttl=1800)` | 展場多人同時操作時不重複連網 |
| 錯誤寫進 `data/app.log` | 靜默失敗最難除錯，必須留痕跡 |

### 模型層

| 決策 | 原因 |
|---|---|
| `StandardScaler` 取代 `MinMaxScaler` | 報酬率有極端值，MinMax 會把正常日子壓在 0.45~0.55 |
| scaler 只用訓練區間 fit | 避免驗證集資訊洩漏（ML 基本錯誤，老師必問） |
| purged split，中間挖 81 個樣本 | 訓練樣本的「答案」會落在驗證樣本的「題目」裡 |
| KMeans 狀態做 one-hot 進 `FEATURE_COLUMNS` | 原版只算不用，KMeans 對預測完全沒作用 |
| 預測改畫折線 + 不確定性區間 | 原版重建的 22 根 K 線長得一模一樣，一眼看穿 |
| 診斷加 naive baseline、標準差比、方向準確率 | 單看 MAE 沒有意義，無法判斷模型是否只是輸出常數 |

### 呈現層

| 決策 | 原因 |
|---|---|
| 系統健檢獨立成第一個分頁 | 外部相依多，要能快速定位是哪一層壞了 |
| TAB4 分「讀已存結果 / 重新訓練」 | 展場絕不現場訓練，網路一斷就開天窗 |
| 偵測不到 TensorFlow 自動切唯讀 | 讓雲端部署不必裝 TF |
| 情緒覆蓋率低於 20% 主動跳警告 | 誠實揭露限制比被抓到好 |

## 四、已知的坑（踩過的）

| 坑 | 症狀 | 解法 |
|---|---|---|
| FinMind `_adj` 需付費 | 回傳 "Your level is free" | 改用 `taiwan_stock_daily`，已自動降級 |
| FinMind 未登入限額 300/hr | 掃描多檔時抓不到資料 | 申請 token 提高到 600/hr（選用） |
| Google News RSS 只給近 2~4 週 | 情緒特徵覆蓋率僅約 1% | 每日累積；或改用 GDELT |
| MSE + 日報酬率 → 模型輸出常數 | 標準差比 0.122、方向 50.0% | 任務設定的必然結果，見實驗 B/C/D |
| Windows 上 TF 不支援 GPU | 顯卡閒置 | TF 2.11 起需 WSL2。模型小，CPU 即可，不建議折騰 |
| `0050` 從 CSV 讀回變成數字 50 | 篩選失效 | `pd.read_csv(dtype={"stock_id": str})` |
| 選單混用字串與整數 | `AttributeError` | 用字典，選單只放字串 |
| TF 的 `tf.reset_default_graph` 警告 | log 裡出現 WARNING | 無害。可 `logging.getLogger("tensorflow").setLevel(ERROR)` |

## 五、實驗記錄

### ✅ 實驗 A：每日報酬率回歸（已完成）

**設定**：TCN，輸入 60 天 × 19 特徵，輸出未來 22 天每日報酬率，損失 MSE
**資料**：0050，5 年，總樣本 1066（訓練 836 / 挖空 81 / 驗證 149），切分日 2025-10-07

| 指標 | 數值 | 判讀 |
|---|---|---|
| 模型 MAE | 0.01585 | 比基準**差** |
| 基準 MAE（永遠猜 0） | 0.01559 | — |
| 模型 RMSE | 0.0214 | 比基準差 |
| 預測標準差 | 0.0026 | 幾乎不動 |
| 實際標準差 | 0.0211 | — |
| **標準差比** | **0.122** | 模型變化幅度僅現實的 12% |
| **方向準確率** | **0.500** | 完全隨機 |

**結論**：模型收斂至近似常數輸出。這是 MSE + 日報酬率的數學必然，非實作錯誤。

## 七、報告定位建議

**不要寫**「我們做出了準確的股價預測系統」。

**建議這樣寫：**

> 本研究建置了一套方法論嚴謹的股價預測實驗框架，並誠實評估其預測能力。
>
> 實驗 A 顯示，以每日報酬率為回歸目標時，模型收斂至近似常數輸出（標準差比 0.122），
> 方向準確率 50.0%，與弱式效率市場假說一致。
>
> 實驗 B、C 改變預測目標設定後（結果待補），實驗 D 則發現波動率具備可預測性（結果待補）。
>
> **結論**：市場的「方向」難以預測，但「風險程度」具有可預測結構。
> 此結果說明機器學習在投資領域的合理定位為風險管理，而非擇時交易。

**新聞情緒要分開講，不要混進模型成效：**

> 新聞情緒分析引擎整合 Google News RSS 與 FinBERT 中文金融情緒模型，
> 提供即時輿情監測，並建置每日自動蒐集機制累積歷史情緒資料庫。
>
> **限制說明**：受限於免費新聞來源僅提供近期資料，情緒特徵於五年歷史訓練資料
> 中的覆蓋率僅約 1%，因此本研究中情緒特徵對預測模型的實質貢獻有限。

**版權聲明：**

> 本系統僅蒐集新聞標題與來源連結，並儲存模型運算後的情緒指標，
> 不重製或散布新聞全文。所有資料僅供本研究之學術分析使用。
